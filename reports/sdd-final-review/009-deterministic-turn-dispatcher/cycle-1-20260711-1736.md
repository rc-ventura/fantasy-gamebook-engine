## Tech Leader Verdict

### Architecture Assessment
The dispatcher is architecturally sound and faithful to ADR-033's core split: `ClassifyIntent` (LLM, no tools) → `MechanicalDispatch` (pure code) → `CombatRound` (cyclic, pure code) → `Narrate` (LLM, `toolsets=[]`). SOLID holds — nodes are single-responsibility, `DispatcherNarrator` slots behind the `NarratorBackend` port with zero route changes (OCP), templates/backbone are data not code. Determinism is clean (encounter rolls use engine RNG, `graph.py:119-123`, honoring ADR-005).

The defect is **not structural drift — it's an incomplete invariant**. ADR-033's decision text asserts params are "bounded by the template schema… cannot choose 50 — the schema rejects." That guarantee is real for `int`/`enum` but **false for `list`/`bool`**: `clamp_params` (`check_engine.py:68-69`) returns them untouched. The `move` template earned an explicit, classifier-independent adjacency guard (`graph.py:376-383`) because a bug was found in it live; `combat` — the highest-stakes template, which fabricates enemies with arbitrary `skill`/`stamina` — got **no equivalent guard**, because the live combat test happened to hit a matched encounter (`archway_guardian`, prob 1.0) and never exercised the no-match path. Guards were added ad hoc per-bug, not as a class invariant. That is the systemic finding.

### ADR Compliance
- ✅ ADR-001 through ADR-032 (excluding ADR-033): Compliant or out of spec-009 scope, untouched.
- ❌ **ADR-033 Engine-side guard against narrator-supplied values: VIOLATED for `combat`.** ADR-033's stated design constraint — *"the primary guarantee must be structural and model-independent… an argument that a stronger model would not do this is empirically falsified"* — is broken on the combat no-match path. This is **the same failure class ADR-033 fixed for `update_character_sheet`, reappearing via a different tool**.
- ⚠️ ADR-026 Postgres TLS policy (spirit): the sibling "refuse-insecure-in-production" posture was silently dropped for OTLP.
- ✅ ADR-035 pydantic-evals offline CI-gated harness: decision recorded, not yet implemented (`grep -r pydantic_evals` → 0 hits). Acceptable per its own scoping, but means the T045 fallback success path currently has no regression net.

📝 **New ADR needed** — *"Every mechanical template must carry an unconditional, classifier-independent authorization guard, not merely type-bounded params."* Generalize `move`'s adjacency check into a stated architectural invariant: before any template's `mandatory_checks` reach the engine, a code-side gate re-derives the legal action set independently of classifier output. This converts three ad-hoc, per-bug guards into one named contract.

### Learning Lessons Applied
- ✅ Probabilistic encounter roll via engine RNG, numbers-never-in-prose, pydantic-ai v2 toolset pattern, scoped toolset wrapper: all applied correctly.
- ❌ **"One live-validation session is not a regression suite" (2026-07-11): Not fully applied — repeated in a new form.** The lesson's own thesis applies verbatim to the **combat no-match path**: the single live combat run hit a matched encounter, so the injection path was never exercised — exactly the blind spot the lesson warns about. Internalized as documentation (ADR-035) but not yet as a mechanism.

### Cross-Report Synthesis
QA and Security describe **one root cause from two angles**: classifier output reaching the engine through a template whose guard is incomplete. Trace the theme across three dated events — ADR-033's original fix, today's `move`/empty-params desync (ADR-035/lesson), and Security's `combat`/unbounded-list injection. All three are "an LLM-proposed value crosses into engine state without a structural, model-independent bound." The project keeps patching the *instance*, not the *class*.

Severity split: Security's combat gap is the one true **blocker** — it defeats ADR-033's model-independent guarantee and is exploitable by construction, not by luck. QA Bug #2 (deleted OTLP production guard, stale comment left describing protection that no longer exists) is High and cheap to restore (~6 lines); at minimum the stale comment cannot ship. Everything else is real but non-blocking. The suite is genuinely green (340/0/80) and SC-001–SC-005 are covered; the gaps are all on paths no test drives, which is itself the lesson-of-the-day.
